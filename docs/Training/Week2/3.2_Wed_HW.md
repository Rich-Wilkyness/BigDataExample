1. **Subquery — Above-Average Prices**
   Find all records in `orderdetails` whose `price` is greater than the **average price across the entire `orderdetails` table**. Return `order_number`, `product_number`, `product_category`, and `price`. Solve this using a **subquery**.

```sql
SELECT * FROM orderdetails
WHERE price > (SELECT AVG(price) FROM orderdetails);
```


2. **CTE — Order Totals**
   Create a CTE named `order_totals` that calculates the total value of each order using:

   ```text
   price × quantity
   ```

   Return only orders whose total value is greater than **5,000**, sorted from highest total to lowest.

```sql
WITH order_totals AS (
    SELECT order_number, SUM(price * quantity) AS total_value FROM orderdetails 
)
SELECT * FROM order_totals
WHERE total_value > 5000
ORDER BY total_value DESC;
```

3. **CTE + Join — Product Revenue**
   Create a CTE that calculates the **total revenue generated by each `product_number`** from `orderdetails`. Then join the CTE to `products` so the final result contains `product_number`, `product_name`, `product_category`, and total revenue. Sort from highest revenue to lowest.

```sql
WITH product_revenue AS (
    SELECT product_number, SUM(price * quantity) AS total_revenue FROM orderdetails
)
SELECT p.product_number, p.product_name, p.product_category, pr.total_revenue 
FROM products p 
JOIN product_revenue pr on p.product_number = pr.product_number
ORDER BY pr.total_revenue DESC;
```


4. **Window Function — Category Average**
   For every record in `orderdetails`, return `product_number`, `product_category`, and `price`, along with the **average price for that product's category**. Use `AVG()` as a window function with `PARTITION BY`. Do **not** use `GROUP BY`.

```sql
-- 
SELECT product_number, product_category, price, AVG(price) OVER (PARTITION BY product_category) AS category_avg_price FROM orderdetails;
```

5. **Window Function — Ranking**
   Rank the products within each `product_category` according to price, with the highest price ranked first. Return `product_number`, `product_category`, `price`, and the rank. Use `DENSE_RANK()` so products with identical prices receive the same rank.

```sql
SELECT product_number, product_category, price, DENSE_RANK() OVER (PARTITION BY product_category ORDER BY price DESC) AS category_rank FROM orderdetails;
```

6. **CTE + Window Function — Top 3 per Category**
   Find the **three highest-priced records in each product category**. Use a window function to assign the ranking and a CTE to allow you to filter the results. The final result should contain only ranks 1–3.

```sql
WITH ranked_products AS (
    SELECT product_number, product_category, price, ROW_NUMBER() OVER (PARTITION BY product_category ORDER BY price DESC) AS category_rank FROM orderdetails
)
SELECT * FROM ranked_products WHERE category_rank <= 3;
```

7. **Window Function — Previous Payment**
   Sort payments chronologically by `payment_date`. For each payment, display `payment_id`, `payment_date`, `amount`, and the amount of the **previous payment**. Use `LAG()`. Add another calculated column showing:

   ```text
   current payment amount - previous payment amount
   ```

```sql
-- LAG() is a window function that allows you to access data from a previous row in the result set. It is often used to compare values between consecutive rows, such as calculating differences or identifying trends over time.
SELECT payment_id, payment_date, amount, LAG(amount) AS previous_payment_amount, amount - LAG(amount) AS amount_difference FROM payments ORDER BY payment_date;
```

8. **Conditional Aggregation**
   Produce one row containing:

   * total number of payments
   * total value of all payments
   * number of payments of at least **1,000**
   * total value of payments of at least **1,000**

   Use `CASE` inside aggregate functions for the last two calculations.

```sql
-- CASE WHEN statements are used to perform conditional logic in SQL queries. They allow you to create new columns or modify existing ones based on specific conditions. In this case, we use CASE statements inside aggregate functions to count and sum payments that meet certain criteria.
-- THEN = the value to return if the condition is true.
-- ELSE = the value to return if the condition is false.
-- END = marks the end of the CASE statement.
SELECT
    COUNT(*) AS total_payments,
    SUM(amount) AS total_value,
    COUNT(CASE WHEN amount >= 1000 THEN 1 END) AS payments_over_1000,
    SUM(CASE WHEN amount >= 1000 THEN amount ELSE 0 END) AS total_value_over_1000
FROM payments;
```

10. **Capstone — Top Products by Revenue**
    Write one query that determines the **three highest-revenue products within each product category**.

    Revenue for a line item is:

    ```text
    price * quantity
    ```

    Your final output must contain:

    ```text
    product_category
    product_number
    product_name
    total_revenue
    category_rank
    ```

    Requirements: join `orderdetails` with `products`; aggregate the individual order lines to calculate total revenue per product; use at least one **CTE**; use a **window function** to rank products within their categories; return only the top three ranks from each category; and sort the final output by category and then rank.

```sql
-- 1 CTE, 1 window function, 1 join
-- top 3 highest-revenue products within each product category
-- use join orderdetails with products
WITH product_revenue AS (
   SELECT product_number, product_category, ROW_NUMBER() OVER (PARTITION BY product_category ORDER BY SUM(price * quantity) DESC) AS category_rank, SUM(price * quantity) AS total_revenue
   FROM orderdetails
   GROUP BY product_number, product_category
)
SELECT p.product_name, p.product_category, pr.product_number, pr.total_revenue, pr.category_rank
FROM product_revenue pr
JOIN products p ON pr.product_number = p.product_number
WHERE pr.category_rank <= 3
ORDER BY p.product_category, pr.category_rank;
```
