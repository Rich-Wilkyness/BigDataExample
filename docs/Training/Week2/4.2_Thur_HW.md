1. **Facts and Dimensions**
   In 2–4 sentences, explain the difference between a **fact table** and a **dimension table**. Then identify one fact table and two dimension tables from the warehouse we created in class.

   - dimension table = these are the points/nodes of the star/snowflake. Depending on how normalized the database, these can be large or small tables describing events/people/places/things. They typically have the suffix `dim_`. EX: gold.dim_customer, gold.dim_product

3. **Querying a Star Schema**
   Write a SQL query using:

   * `gold.fact_sales`
   * `gold.dim_product`
   * `gold.dim_date`

   Return the **total sales amount by product category and year**, ordered by year and total sales descending.

   ```sql
    SELECT SUM(sales_amount) AS total_sales_amount, p.product_category, d.year
    FROM gold.fact_sales fs
    JOIN gold.dim_product p ON fs.product_key = p.product_key
    JOIN gold.dim_date d ON fs.date_key = d.date_key

   ```

9. **Bronze → Silver with Pandas**
   The Bronze data contains the following records:

   ```text
   transaction_id | category      | quantity | unit_price
   T101           | electronics   | 2        | 50.00
   T102           | ELECTRONICS   | 3        | 75.00
   T103           | Furniture     | -2       | 200.00
   T104           | electronics   | 1        | INVALID
   ```

   Write Pandas code that:

   * standardizes `category`
   * converts `quantity` and `unit_price` to numeric values
   * converts invalid values to `NaN`
   * removes rows where quantity or price is invalid
   * removes rows where quantity is 0 or negative
   * creates `sales_amount = quantity * unit_price`

   ```python
    df = pd.read_sql("SELECT * FROM bronze.sales_transactions", connection)

    standardCatDF = (
        df.assign(
            category = (lambda data: (
                data["category"]
                .str.strip() # remove whitespace
                .str.upper() # capitalize every letter
            ))
        )
    )

    ensureNumericDF = (
        standardCatDF.assign(
            # check if numeric value, if false -> do what error says
            unit_price = lambda data: pd.to_numeric(
                data["unit_price"], errors = "coerce" # coerce makes INVALID = NaN
                ),
            quantity = lambda data: pd.to_numeric(
                data["quantity"], errors = "coerce"
                )
        )
    )

    filterOut = (
        ensureNumericDF
        # dropna = Check these columns and remove the entire row if either column contains NaN.
        .dropna( 
            # subset = decides what columns to look at
            subset=["unit_price", "quantity"]
        )
        .loc[
            lambda data: data["quantity"] > 0 # keep data that is greater than 0
        ].copy() # create independent DataFrame for next transformation
    )

    salesAmountDF = (
        filterOut.assign(
            sales_amount = lambda transaction: (
                transaction["quantity"] * transaction["unit_price"]
                )
        )
    )

    salesAmountDF.to_sql("silver.sales_transactions", index=False)

   ```
