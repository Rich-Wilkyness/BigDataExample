# Part 1 — Coding Assignment: Build a Streaming Market Aggregation

Using the existing simulated stock-market Kafka topic, create a **new consumer** that calculates useful market statistics.

You may implement this using **either Spark Structured Streaming or Flink**.

Do not modify the existing dashboard consumers. Create a new file such as:

```text

```


## Input

Consume records from the existing:

```text
market_ticks
```

Kafka topic.

A market event contains information similar to:

```json
{
    "sequence": 15231,
    "symbol": "AAPL",
    "price": 226.37,
    "size": 100,
    "side": "BUY",
    "exchange_ts": "2026-09-30T15:31:07.123Z",
    "api_ts": "2026-09-30T15:31:07.128Z",
    "kafka_ts": "2026-09-30T15:31:07.134Z"
}
```

Your consumer should parse the JSON and calculate statistics **for each stock symbol**.

At minimum calculate:

```text
symbol
number_of_trades
average_price
minimum_price
maximum_price
total_volume
```

For example, your output might conceptually look like:

```text
+------+----------------+-------------+-------------+-------------+-------------+
|symbol|number_of_trades|average_price|minimum_price|maximum_price|total_volume |
+------+----------------+-------------+-------------+-------------+-------------+
|AAPL  |105             |226.31       |225.94       |226.71       |14820        |
|GOOG  |98              |195.17       |194.82       |195.49       |12640        |
|MSFT  |101             |431.28       |430.91       |431.63       |13950        |
+------+----------------+-------------+-------------+-------------+-------------+
```

Your numbers will be different because the market data is continuously generated.

## Requirements

Your program must:

1. Read continuously from Kafka.
2. Parse the incoming JSON.
3. Group records by `symbol`.
4. Calculate:
   - count of trades
   - average price
   - minimum price
   - maximum price
   - total traded volume (`size`)
5. Continuously display the updated results.

You do **not** need to build another Streamlit application.

### Bonus

Instead of calculating statistics over all events since the program started, calculate them over a **time window**.

For example:

```text
AAPL statistics for 15:30–15:31
AAPL statistics for 15:31–15:32
AAPL statistics for 15:32–15:33
```

Use `exchange_ts` as the **event time**.
