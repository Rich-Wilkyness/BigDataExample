## Part 2 — DLT and Lakeflow Reading

**Estimated time: 30–40 minutes**

Read enough to understand the concepts demonstrated in class. You are not expected to memorize the APIs or build another complete pipeline tonight.

### A. Lakeflow Spark Declarative Pipelines

Read: [Databricks — Lakeflow Spark Declarative Pipelines](https://learn.microsoft.com/en-us/azure/databricks/ldp/)

Focus on:

- What Delta Live Tables (DLT) was and how it relates to Lakeflow.
- The difference between a traditional Databricks notebook and a declarative pipeline.
- How Lakeflow determines dependencies between datasets.
- The distinction between streaming tables and materialized views.
- Triggered versus continuous pipeline execution.

### B. Data Quality Expectations

Read: [Databricks — Manage Data Quality with Expectations](https://learn.microsoft.com/en-us/azure/databricks/ldp/expectations)

Understand the three common behaviors:

- `expect`: Track invalid records without automatically dropping them.
- `expect_or_drop`: Exclude records that violate a rule.
- `expect_or_fail`: Fail the update when invalid data is encountered.

Think about which rules would be appropriate for the Citi Bike Silver layer.

### C. Auto Loader and Incremental Processing

Read: [Databricks — What is Auto Loader?](https://learn.microsoft.com/en-us/azure/databricks/ingestion/cloud-object-storage/auto-loader/)

Focus on:

- How Auto Loader detects newly arriving files.
- Why checkpointing matters.
- How incremental processing differs from rereading all historical files.
- How Auto Loader can be used in a Lakeflow streaming table.
