# Homework Assignment: Cloud Data Migration and Processing

**Topics:** Google Cloud Storage Transfer Service (STS), AWS Database Migration Service (DMS), Google Cloud Storage (GCS), BigQuery, Dataflow, and Dataproc

**Primary Focus: Capstone Project Development**

## Part 1: Reading and Review (20–30 Minutes)

This assignment reinforces the cloud migration and data processing technologies covered in class. Keep the reading light and focus on understanding when and why each service would be used.

### 1. Google Cloud Storage Transfer Service (STS)

STS is a managed service for transferring data between storage systems, including Amazon S3 and Google Cloud Storage.

Review the following concepts:

- Transferring files from Amazon S3 to GCS.
- Configuring source and destination buckets.
- Authentication, IAM roles, and service accounts.
- Scheduling one-time and recurring transfers.
- Monitoring transfer jobs and troubleshooting permission errors.

**Reading:** [Google Cloud Storage Transfer Service Overview](https://cloud.google.com/storage-transfer/docs/overview)

### 2. AWS Database Migration Service (DMS)

AWS DMS is used to migrate data between databases and supported targets, including Amazon S3.

Review:

- The difference between database migration and object storage transfer.
- Full-load migration versus Change Data Capture (CDC).
- Source endpoints, target endpoints, and replication tasks.

**Reading:** [AWS DMS Overview](https://docs.aws.amazon.com/dms/latest/userguide/Welcome.html)

### 3. Google Cloud Data Processing Services

Review the following services and their roles in a modern data pipeline:

| Service | Primary Purpose |
|---|---|
| **Google Cloud Storage (GCS)** | Store raw and processed data in cloud buckets. |
| **BigQuery** | Analyze large datasets using SQL in a serverless data warehouse. |
| **Dataflow** | Run batch and streaming data processing pipelines, commonly using Apache Beam. |
| **Dataproc** | Run Apache Spark and other open-source big data processing frameworks on Google Cloud. |

**Optional reading:**

- [BigQuery Introduction](https://cloud.google.com/bigquery/docs/introduction)
- [Dataflow Overview](https://cloud.google.com/dataflow/docs/overview)
- [Dataproc Overview](https://cloud.google.com/dataproc/docs/concepts/overview)

## Part 2: Short Review Questions (15–20 Minutes)

Answer each question in 2–3 sentences.

1. What is the difference between Google Cloud Storage Transfer Service and AWS Database Migration Service?
2. Why are IAM permissions important when transferring data between AWS and Google Cloud?
3. How could STS, GCS, Dataflow, and BigQuery work together in a single data pipeline?
4. When might you choose Dataproc instead of Dataflow?
5. What are the advantages of using managed cloud services instead of building and maintaining your own migration and processing infrastructure?

These questions are intended to reinforce the concepts, not require extensive research.

## Part 3: Optional Hands-On Practice

If you have time and appropriate cloud access, practice one of the following:

- Create a small Storage Transfer Service job to move sample files from Amazon S3 to GCS.
- Explore a GCS bucket and examine its folder structure, objects, and IAM permissions.
- Create a BigQuery dataset and load a small CSV or JSON file from GCS.
- Review an Apache Beam pipeline and identify its transformations and output destination.
- Explore the Google Cloud Dataproc interface and review the available Spark execution options.

**Important:** Hands-on practice is optional. Avoid unnecessary cloud spending, and delete unused resources when finished.

## Part 4: Main Homework — Capstone Project Development

**This is the most important part of the assignment.**

Continue developing your capstone project and prepare for your upcoming presentation or demonstration.

Your priority should be making meaningful progress on your existing project rather than spending excessive time on the reading or optional exercises.

Focus on the following areas:

1. **Pipeline development:** Continue building or refining your ingestion, transformation, storage, and analytics components.
2. **Integration:** Ensure that the different components of your project can communicate and exchange data correctly.
3. **Testing and troubleshooting:** Identify problems, resolve errors, and verify that your pipeline produces the expected results.
4. **Documentation:** Prepare a simple architecture diagram and be ready to explain the purpose of each major component.
5. **Presentation preparation:** Make sure you can demonstrate your project's main functionality and explain the technical decisions behind it.

If your project involves data migration, consider whether STS or DMS could be useful. If it involves data processing or analytics, consider how services such as GCS, Dataflow, Dataproc, or BigQuery fit into the architecture.

You are **not required to incorporate every service covered in this assignment**. Use the technologies that make sense for your project's requirements.
