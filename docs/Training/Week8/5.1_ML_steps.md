# Friday ML demonstration route

Use the [demo index](friday-ml-demos/README.md) for the runnable guides and their own files. This page is the reading route; commands are maintained inside each demo so there is one current procedure per task.

## Prepare

Read the [main lecture](5_Fri_ML_Flow.md), check the [local requirements/key matrix](friday-ml-demos/local-requirements.md), then complete [data preparation](friday-ml-demos/data-preparation.md) and [shared setup](friday-ml-demos/setup.md). The Kafka baseline is now Kafka 4.4.0 with KRaft and Java 17+, using the included commented configuration. A fresh lab needs one-time storage initialization; normal restarts only start the Kafka process.

## Evidence boundary

The conversations report classroom results, including regression MAE 6.09/R² 0.652 and sixth-run synthetic fraud accuracy near 98.8%; those results have not been reproduced here. The [verification record](friday-ml-demos/verification.md) includes executed station/model checks and offline workflow tests; real Kafka/provider/trace integration remains separately identified. The updated record includes a read-only AWS snapshot export, local station-model execution, and local MLflow artifact checks. It does not establish a live Kafka 4.4.0 pipeline, provider requests, or successful trace export.
